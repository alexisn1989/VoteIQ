# VoteIQ Pricing & Tiers (4 Verticals)

## Overview

VoteIQ has four chat verticals, each with tailored agents, features, and pricing.

---

**Audience:** General public, engaged citizens, advocacy
**Mission:** "Understand how your government works"

### FREE
```

- Mode selector (analyst, support)
- Source citations + data limits
- Report data issue button
- Read-only access

Price: Free
Goal: Conversion funnel to Pro
```

```

✓ visual_explainer (25/month)
```
