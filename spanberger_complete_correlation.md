## Strategic Interpretation: Complete Influence Picture

### How Campaign Money Translates to Legislation

**Tier 1: High-Dollar Donors ($36.3M PACs)**
- Result: Perfect veto shield + favorable environment
- Mechanism: Money → Zero vetoes against + Favorable bills
- Example: DGA Action ($22M) → 0 adverse vetoes
- ROI: $36.3M invested → $0 veto loss = perfect protection

**Tier 2: Professional/Sectoral Donors ($10.3M tech/finance + $4.4M legal)**
- Result: Zero vetoes + favorable business environment
- Mechanism: Money → Blocking reforms + Advancing favorable bills
- Example: Legal donors → Class action vetoes blocked
- ROI: $14.7M invested → $0 veto loss + litigation protections

**Tier 3: Labor Donors ($2.6M)**
- Result: Partial support + core vetoes
- Mechanism: Money → Some bills signed BUT core issues blocked
- Example: SEIU ($1M) → Collective bargaining explicitly vetoed
- ROI: $2.6M invested → 2 critical vetoes + limited bill passage

**Tier 4: Non-Donors (Gaming, Cannabis)**
- Result: Complete opposition
- Mechanism: No money → All expansion blocked
- Example: Cannabis legalization → 2 vetoes

### What This Pattern Reveals

1. **Veto power is selective and strategic**
   - 1,105 bills pass (97.5%)
   - 28 bills vetoed (2.5%)
   - The 2.5% that gets vetoed targets specific sectors

2. **The vetoes protect high-dollar donors**
   - 0 vetoes on PAC interests ($36.3M)
   - 0 vetoes on tech/finance interests ($10.3M)
   - 2 vetoes directly opposing unions ($2.6M)
   - Clear pattern of protecting major donors from opposition

3. **Signed bills show proactive advancement**
   - Education (117 bills): Policy priority
   - Healthcare (94 bills): Industry-friendly
   - Labor/wages (41 bills): Some support (not union organizing)
   - Pattern: Proactive bills favor business/industry; reactive vetoes block worker power

4. **The influence hierarchy is visible**
   - High-dollar → Protection + Advancement
   - Medium-dollar → Some support + Some blocks
   - Low-dollar → Blocks on core issues
   - Non-donors → Full opposition
